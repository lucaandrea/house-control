# Loft 113

The personalized plan is [`web/public/plans/loft113.json`](../web/public/plans/loft113.json).
Load it with **Load floor plan…**. Open **Home Map…** from the menu bar menu, or use the
expand button in the compact panel. **Ground + patio** and **Bedroom loft** share the same
horizontal coordinates and display separately so the bedroom does not cover the rooms below.
The editor's **Edit floor** selector limits selection, dragging and the 3D preview to that floor.

## Evidence and scale

The owner's room sequence takes priority over neighboring layouts. The model uses the 20
supplied apartment photos, preferring the newer arrangement when photos disagree, plus the
provided plans of units 111 and 201. The newer bedroom photos (IMG_8056 and IMG_8057) guide
the bed, bedside tables, dresser and reading area. Photos remain outside the repository.

Camera EXIF timestamps confirm the sequence: the bedroom pair is September 30, 2026;
IMG_8252 2 shows the living-room windows on October 6; IMG_8416 shows the bathroom
HomePod placement on October 11. Archive dates are all October 14 and do not establish
the order in which the photos were taken.

The six-page annotation packet has reached revision 3. Each local review manifest preserves the
exact plan, the L/D callout-to-device mapping, photo chronology and PDF fingerprint,
so returned annotations can be reconciled even after later app edits. Review exports
and the baselines remain outside Git under `output/pdf/`. The owner's marked revisions and
previous active plans are preserved there too. L/D codes retain the same identities; L20 is
reserved for the removed upstairs ceiling light and is no longer shown on the active map.

The repeatable packet builder is `script/export_loft_review.py`. It accepts a directory containing
`ground-render.png`, `loft-render.png`, a `footprints.json` array generated by the renderer's
`footprint()` function for the same plan, and `review-notes.json` with `changes`, `pending` and
`notePrompts` by floor. Run it with `--assets <directory> --revision <number>`.
The previous revision's manifest preserves callout identities, including retired device labels.
The packet keeps furniture plans first, device maps next, and clean angled renders on pages 5-6.

## What is represented

- Ground floor: entrance, racing nook with sleeper sofa and triple-screen rig, left-side laundry,
  guest bath, kitchen and bar, dining, stairs, double-height living area, media wall, cream sectional,
  red fireplace column, piano, computer desk, three glazed bays and plants.
- Loft: stair opening and railings, bed against the right wall, bedside tables, long dresser,
  reading nook, closets, carpet, plants and bathroom with double vanity.
- Patio: lounge seating, fire bowl, dining table, turf, bamboo planting and decorative lights.
- Lighting: 22 mapped fixtures or circuits, including the under-bar strip, bed rope, bedside lamps,
  tree lamp, two linked patio strings and outdoor strip. Counts within Lutron circuits are unverified.
- Equipment: 23 inventory entries including the washer/dryer, three cameras, AV and network gear,
  blinds, fan, Eight Sleep bed/hub, three HomePod minis, purifier, scent/humidity device and sensor.

The five scenes are local lighting previews. The plan contains no discovered hardware identifiers.
Inventory tiles explicitly say **Mapped · not connected** and do not invent controls or sensor readings.
Supported light integrations can be linked later in the editor. Other inventory categories need
appropriate integration support before live controls can be offered.

## Refinement still needed

Wall and window measurements, patio depth, stair rise/run, bathroom fixture dimensions and closet
details remain estimates. The entrance, laundry and racing nook were not visible in the supplied
photos, so those use the owner's description, markup and neighboring plans. Exact equipment models,
device names, circuit membership and live state require a connected inventory and on-site checks.

## Validation

The web tests cover floor isolation, legacy plans, preserving hardware links, cross-floor edits,
non-overlapping room zones, finite furniture geometry, laundry footprints and the sectional's
open corner. Build with `./script/build_and_run.sh`;
run web tests with `cd web && npm test` and shared native tests with `cd core && swift test`.
